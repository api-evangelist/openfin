# OpenFin (HERE)

> OpenFin — now branded HERE — is the operating-system layer for enterprise financial desktops. Its container/runtime lets web applications run as secure, interoperable desktop apps, with Workspace surfaces (Home, Dock, Store, Notifications, Browser) and FDC3-based interop. The developer surface is a JavaScript `fin` runtime API (plus Java and .NET adapters), not a REST/HTTP API. Backed by Bain Capital Ventures; widely deployed across banks and financial institutions.

## SDKs & Packages
- [@openfin/core](https://www.npmjs.com/package/@openfin/core): Core container runtime API.
- [@openfin/core-web](https://www.npmjs.com/package/@openfin/core-web): Interop + layouts in the browser.
- [@openfin/workspace](https://www.npmjs.com/package/@openfin/workspace): Workspace integration API.
- [@openfin/fdc3-api](https://www.npmjs.com/package/@openfin/fdc3-api): FDC3 interop utilities and types.
- [@types/openfin](https://www.npmjs.com/package/@types/openfin): TypeScript definitions.
- [@openfin/cloud-api](https://www.npmjs.com/package/@openfin/cloud-api): Cloud Platform client.
- Java + .NET adapters: [github.com/openfin](https://github.com/openfin).

## Standards
- FDC3 (Financial Desktop Connectivity and Collaboration Consortium) interop.
- SOC 2 (AICPA SOC certified) and FSQS Registered (see conformance/openfin-conformance.yml).
